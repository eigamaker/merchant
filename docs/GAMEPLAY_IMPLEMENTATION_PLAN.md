# Dungeon Curio Merchant — Web版ゲーム方針・実装計画

更新日: 2026-08-18
状態: Web版を本開発対象とする方針整理

## 1. 対象プロジェクト

この文書は、Phaser/Viteで動作するWeb版だけを対象とする。Unity版の実装計画は `C:\development\merchan-Unity\docs\GAMEPLAY_IMPLEMENTATION_PLAN.md` に置く。Web版からUnityのコード、Prefab、Scene、Packageを参照しない。

## 2. ゲーム方針

- 自宅兼店舗とダンジョンを往復する
- 店舗を準備・保管・陳列・販売のホームにする
- ダンジョンは画面切替のコマンド戦闘ではなく、同じフィールド上で解決する
- 主人公は商人で、護衛を主戦力とする
- 主人公と護衛は論理上同じマスの隊列として移動し、護衛は隣接する敵への攻撃とカバーを自動で行う
- 護衛はNPCごとのHP基準で後退し、敵が索敵範囲外の状態が2ターン続くとカバーへ復帰する
- 敵を倒したら残骸・遺体を生成し、調べてアイテムを回収する
- 店舗の商品は顧客が棚から欲しい`ItemInstance`を指定し、希望購入額で商人が承諾した後に売却記録へ移す

## 3. 直接操作

通常行動のたびに共通メニューを開かない。対象物と主人公の向きから文脈操作を解決する。

| 入力 | 予定動作 |
| --- | --- |
| `WASD`／方向キー | 移動・向き変更 |
| `E` | 拾う、調べる、遺体探索、棚、会話、扉 |
| `R` | 正面の敵を押し出す |
| `F` | 選択中の武器・道具を使う |
| `C` | クイック消耗品を使う |
| `1`〜`5`／ホイール | 手持ちスロット切替 |
| `Enter` | 道具袋・保管整理 |
| `Space` | ダンジョンで待機 |

入力とルールは`src/game/`に置き、画面表示は`src/scenes/`とUIへ分離する。ダンジョンの有効な行動だけが護衛・敵のターンを進める。

## 4. インベントリ

- 道具袋は24枠で、アイテムを種類に関係なく24個まで管理する
- クイックスロットは道具袋内の同じアイテムを参照する
- 手持ちは選択中の1枠で、武器・道具の`F`動作を決める
- 棚、床、遺体、道具袋、売却記録は同じ`ItemInstance`の場所として扱う
- IndexedDB保存は現端末・現ブラウザ用。クラウド保存はサーバー機能を追加する段階で扱う

## 5. 実装順序

1. 自宅店舗とダンジョンの遷移を現在のPhaserシーンへ整理する
2. 直接操作、道具袋、クイックスロット、ターン消費を実装する
3. 護衛AI、敵AI、押し出し、攻撃、遺体探索を統合する
4. 棚、顧客、待ち列、会計、返品を物理店舗へ移す
5. 1日の開始・営業終了・帰還・再出発とセーブを接続する
6. Web公開用のビルド、アセット容量、ブラウザ互換性を検証する

## 6. 検証

```powershell
npm test
npm run build
```

Web版で変更したアセットは`public/assets/`へ配置し、Unity側へコピーしない。Unity版の素材はUnityリポジトリで独立して管理する。
