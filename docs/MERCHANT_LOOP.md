# 商人ゲームループ v5

## 実装済みの最小ループ

1. 自宅兼店舗からダンジョンへ出発する。
2. 地面・宝箱・死亡した冒険者の遺体から商品を回収する。
3. 24枠の鞄でアイテムを24個まで持ち帰り、チェック式の一括操作で保管庫または店頭へ振り分ける。重さの概念はなく、すべて1個で1枠。探索用品の数値カウンターは枠を使わない。
4. 日ごとに3〜6人の来客があり、棚の商品を1点指定して希望購入額を提示する。商人は売るか断るかを決める。
5. 探索前にE〜Aランクと冒険者本人を指定し、ランク基準の護衛料を前払いして1人同行させられる。

商人のHPが0になるとキャンペーンはゲームオーバーになる。同じキャンペーンIDの自動保存・手動保存は削除され、死亡済みIDとして記録される。

ダンジョンでは通常行動1、階段移動5として探索時間が進み、25ごとに携行食料を1つ消費する。食料が0になると主人公に空腹エフェクトが表示され、以後25ごとに2ダメージを受ける。HUDには次の食料消費または空腹ダメージまでの残り時間を表示する。

## コンテンツ定義

- アイテム定義: `src/game/merchantContent.ts` の `MERCHANT_ITEM_DEFINITIONS`
- アイテム画像参照: 同ファイルの `ITEM_VISUALS`
- NPC初期データ: 同ファイルの `NPC_SEEDS`
- 職業別外見参照: 同ファイルの `NPC_APPEARANCES`
- 実行用画像: `public/assets/items/<item-id>.png`
- 生成原本: `assets-src/items/generated-originals/<item-id>.png`

ゲームデータは画像のファイル名を直接保持せず、アイテムは `visualId`、NPCは `appearanceId` を保持する。今後のアセット差し替えでは対応表だけを変更し、セーブデータ上のNPC・アイテムIDを維持する。

## NPCと一点物

初期NPCは15人で、能力値の異なる冒険者10人と一般客5人からなる。冒険者はE・D・C・B・Aの5ランクに分かれ、ランクごとに護衛料と推奨到達階が決まる。同ランク内でもHP、攻撃、後退基準が異なるため、商人が本人を指定して契約する。高ランクほど費用は高いが、深層の強敵に耐えやすい。

| ランク | 基準護衛料 | 推奨到達階 |
|---|---:|---:|
| E | 100G | 地下2階 |
| D | 180G | 地下3階 |
| C | 320G | 地下5階 |
| B | 550G | 地下6階 |
| A | 900G | 地下8階 |

ダンジョンの遺体と独立行動する冒険者は探索時に別の名前付きNPCとして生成され、初期15人を消費しない。各階には2人が登場し、階層に応じたランクと個体差のある能力を持つ。護衛がHP0になった場合も永久死亡し、その場に所持品と遺体を残す。

レジェンダリーの黒剣はキャンペーン内で一点だけ生成できる。発見時は「？？？の剣」で、最初の購入者が名前を付ける。生成・売却・命名・所有者死亡・遺体からの回収はインスタンス履歴へ保存される。

武器と防具は装備でき、回復値を持つ薬や薬草は探索中に主人公または護衛へ使用できる。使用は1ターンを消費する。

各ダンジョン階には独立行動する名前付き冒険者たちが現れる。彼らは敵へ近づいて戦い、負傷時には所持する回復品を使う。正面に立って調べると互いの所持品を売買できるため、負傷した冒険者へ回復品を売ることもできる。死亡した冒険者は所持品を遺体へ残し、主人公はその場で回収できる。
