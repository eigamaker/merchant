# 自動生成アセット・マップエディター

`npm run edit` で `/review.html` を開くと、最初に「素材パレット編集」が表示されます。通常プレイのダンジョンは `procedural` モードで自動生成され、保存した素材パレットを使って「ダンジョンテーマ」で床、階段、装飾を割り当てます。

壁だけは扱いが違います。「ダンジョンテーマ」の「壁」では、展開済みオートタイル（`autotile.scheme` が `blob47` の素材）を**1つ選ぶだけ**です。8近傍から自動で接続先が決まるため、マスクごとのフレーム指定は不要です。選択すると先頭タイルの帯がプレビューされます。従来の16フレーム方式（`wallFrameByMask`）のテーマは、そのままマスク一覧で編集できます。

「手動マップ（任意）」は比較・試遊用として残しています。マップJSONはv6で、パレットの座標を保存せず`assetId`と`frame`だけを保存します。そのため、パレットを後から並べ替えても既存の手動マップの見た目は変わりません。

## 素材と自由配置パレット

素材シートは `assets-src/map-tiles/sheets/` にPNGと同名の`.tileset.json`を組で投入します。生成手順と設定項目は [MAP_TILE_PIPELINE.md](MAP_TILE_PIPELINE.md) を参照してください。

「素材パレット編集」の左側に取り込んだスプライトシート、右側にパレットを表示します。素材一覧は家/ダンジョンでは分けず、「すべて」「16px」「32px」でセルサイズを切り替えます。名前検索や「一覧更新」も利用できます。各カードには実画像とセルサイズが表示されます。素材画像を選んでから方眼で単体または矩形を選択し、右側の同じセルサイズのパレットへドラッグして置きます。パレット内は空白を含む任意の配置で、用途を限定せず好きな大きなパレットを作成できます。

- パレット上のドラッグで矩形を選択する。
- 選択範囲をドラッグすると移動し、`Shift`を押しながらドラッグすると複製する。
- `Delete`で選択セルを消去する。ページの縮小は、縮小範囲に素材が残っていると拒否される。
- ページには自動生成・手動マップ側との互換性のため家/ダンジョン属性が残りますが、素材の配置可否は16px/32pxのセルサイズだけで決まります。1ページに多数の素材を集約できる巨大な作業面で、新規ページは選択中の素材サイズを引き継いだ2048×2048セルとして作成します。必要に応じて最大4096×4096セルまで拡縮でき、追加、改名、拡縮、削除、Undo/Redoは手動で行います。
- 巨大なページは素材が存在する左上の作業範囲だけを等倍表示し、端へ素材を置くと表示範囲が自動的に広がります。ページ全体を縮小画像として描画しないため、16px/32px素材の画質は保持されます。
- 開発中は「保存」が`PUT /__map-editor/palettes`へ保存する。本番ビルドではJSON書き出しのみを提供する。

パレット上部の「選択範囲の仕分け」で、選んだ矩形にまとめて用途（床／壁／小物／階段／水・溶岩）と状態（使える／未整理／不採用）を付けられます。不採用には理由を残せるので、同じシートを何度も見直さずに済みます。用途を付けたセルは右上に色の点が付き、不採用のセルは暗く表示されます。右端に「◯枚中 未仕分け ◯」と残作業が出ます。

この仕分けはダンジョンテーマの素材ピッカーに効きます。「用途」で絞り込むと該当するセルだけが並び、不採用のセルは最初から候補に出ません。

パレットの矩形選択はマップ上のスタンプです。鉛筆は選択範囲の左上を配置し、矩形ツールは範囲内で繰り返します。空白セルはマップ上の既存タイルを消しません。スタンプの素材セルがマップ外へ出る操作は、部分的に配置せず拒否されます。塗りつぶしは単一セル選択時のみ使えます。

左メニューの「レイヤー」で作業対象を選びます。配置、消去、スポイトは選択中の`ground`、`structure`、`decoration`のいずれかだけに作用します。各レイヤーの表示チェックはキャンバス上の可視状態だけを切り替え、保存済みのセルは削除しません。パレット配置では通行設定を変更せず、通行可否は道具の「通行可」「通行不可」で明示的に編集します。どちらも鉛筆と同様に、押したままドラッグして連続したセルを設定できます。「通行表示」をオンにすると可否を青／オレンジのオーバーレイで確認できます。

## マップ設定とマーカー

以下は「手動マップ（任意）」だけの機能です。通常プレイの自動生成ダンジョンには使用しません。

ツールバーの「一覧表示」はマップ一覧を切り替えるだけで、編集対象を変更しません。「マップ種類」「幅」「高さ」「セル」は新規作成と「サイズを適用」の設定値です。既存マップの種類変更は、タイル・collision・マーカーがすべて空の場合だけ可能です。家へ変更する場合は既存の家がないことを確認し、ダンジョンへ変更する場合は次の階数を割り当てます。種類・セルサイズ・幅・高さは一つの操作として適用され、どれかが拒否された場合は何も変更しません。

幅・高さは4〜256セルです。サイズの縮小は左上を保持し、切り落とす範囲にタイル、通行可設定、またはマーカーがある場合は拒否されます。セルサイズの変更は、タイル・collision・マーカーがすべて空のマップにだけ可能です。大きなマップはブラウザのcanvas上限を超えないよう自動縮小表示されますが、セル座標と編集操作は変わりません。

家には`homeSpawn`、`dungeonEntrance`、`homePreparation`、`homeVisitors`が必要です。店の動線には`shopkeeperCounter`と`customerCounter`を使います。保管・陳列はゲーム内メニューから行うため、専用マーカーはありません。ダンジョンの各階には`stairsUp`が必要で、次階がある場合は`stairsDown`も必要です。階段はパレットで単一セルを選んでから配置し、そのセルが階段の見た目としてマーカーに保存されます。

ツールバーの「地下階」で選択中のダンジョンを地下1階、地下2階のように指定できます。既存階へ移動すると、間にある階は自動的に前後へずれて、1階からの連続性と階段接続を維持します。

「編集マップでゲーム開始」は家と全ダンジョン階を一つの実行パックとしてブラウザーへ保存し、その編集内容を使ってゲームを開始します。ダンジョン階は1階から連続した階数である必要があります。この実行パックは同じブラウザーのローカルストレージに保存される開発・確認用データです。

比較用の固定マップは `assets-src/maps/default-map-pack.json` です。通常ゲームのダンジョンは自動生成され、URLで `dungeon=fixed` を指定した場合だけ同梱ダンジョン階を使用します。エディターの保存領域が空の場合は、この既定パックを手動編集の初期データとして読み込みます。既存の編集データは自動上書きしません。

## 素材取込と敵ロスター

「素材パレット編集」の「素材を取り込む」からZIP、TMX/TSX、PNGを解析できます。解析結果は承認前に保持され、候補ごとにマップ素材またはアクター、グリッド、用途、レイヤー、通行可否、敵ステータスを確認します。男性キャラクターのようなTMXはアクター候補へ分類され、マップシートには自動登録されません。

候補は判定した形式ごとにまとまります。「形式不明」「カタログ区分」、および警告の付いた分類は最初から開き、判断の要らない分類は畳んだ状態で表示します。分類ごとに全選択／全解除ができます。

- **オートタイル**: ウディタ形式のシートです。展開後の先頭タイルをプレビューに表示します。セルサイズ・余白・間隔は展開結果から決まるため編集欄はありません。
- **カタログ区分**: 見出し帯で区切られた区画です。切り出した帯の画像を各行に表示するので、そこに描かれた日本語を読んで名前を付けます。名前は登録時のラベルになります。
- **通常グリッド**: 従来どおりセルサイズ・余白・間隔を確認します。
- **形式不明**: 既定では未選択です。セルサイズを手動指定するか、登録から外します。

取込元が`.tile`を含む場合は、作者が付けたタイルセット構成を候補一覧の上に表示します。ダンジョンテーマを組むときの下書きとして参照できます。

解析画面の「全候補を選択」後に「まとめて登録」を押すと、チェックしたマップ素材とアクターを一度に登録できます。マップ素材は `assets-src/map-tiles/sheets/imported/<取込元>/` にPNGと`.tileset.json`として保存され、アクターは `assets-src/actors/imported/<取込元>/<actorId>/` にアクション別PNGと`actor.json`として保存されます。登録後は生成カタログを再構築します。マップ素材からの自動パレットページ作成は既定でオンです。不要な場合だけチェックを外します。アクターはパレットには入らず、アクターカタログと敵ロスターから使用します。

## 出現表

「出現表」タブで、テーマごとに「誰が・どの階層に・どの重みで出るか」を一覧編集します。行は敵・最浅階・最深階・重み・種別（通常／強敵）・階あたりの上限からなり、右側の帯がB1〜B16のどこに出るかを示します。

1階に置く敵の数は固定ではなく**予算制**です。階ごとの予算を、敵の格に応じたコストで消費します。格の高い敵ほど高コストなので、強い敵を入れると自然に体数が減ります。表の下の「階ごとの想定体数」は、最も安い敵だけで埋めた場合の上限です。候補がまったく無い階は「空」と赤く表示されるので、深さの穴が編集中に分かります。

従来の3段階（shallow／middle／deep）の敵プールも読み込めますが、新しいテーマは出現表を使います。ダンジョンテーマの敵プールには、組み込みのcraftpix12体だけでなく、取り込んだ敵アクターも指定できます。以前は組み込みの12体しか許可されておらず、手動マップの敵ロスターでは選べるのにテーマでは保存できない状態でした。

登録した敵アクターは、ダンジョン階の「敵ロスター」で選択します。ロスターは出現するキャラクターの集合だけを保存し、敵数と座標は試遊開始時にランダム決定します。HP、階ごとの加算値、攻撃力はアクター定義へ保存され、敵ロスターが空なら敵なしの階になります。家のロスターは常に空でなければなりません。

「キャラクター」タブでは全アクター（敵・NPC・プレイヤー）を画像カードから選び、動作と方向を再生できます。編集するのは表示名、役割、そして**系統（重／群／術／伏）と格（ティア1〜5）**です。HPや攻撃力は直接入力しません。深さに応じた実際の数値は `src/game/dungeonDifficulty.ts` の曲線が決め、フォーム下の表にB1／B5／B10の結果が出ます。系統や格を変えると表がその場で更新されます。「能力値・役割を保存」で `assets-src/actors/actor-settings.json` に保存します。開発サーバーでは保存後に生成カタログも更新され、敵ロスターとゲーム実行時の敵定義へ反映されます。マップ編集タブの上部にはTeamsの参加者欄に似た「このマップの登場キャラクター」帯があり、ダンジョンで出現候補にする敵を画像カードで切り替えられます。家ではプレイヤー・NPCを確認用に表示します。

ダンジョン階を削除すると、後続階は自動的に前へ詰められます。階段接続は階番号で解決するため、削除確認にも接続先が変わることを表示します。新規作成・複製では最小の欠番を使い、`1, 3`の状態なら次は2階になります。重複した階番号を検出した場合は、接続が曖昧なまま新しい階を作らずエラーを表示します。
