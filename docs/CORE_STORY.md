## 2. 作品の核

> 幼い日に自分が誘った洞窟で友を失った主人公は、自責を抱えながら、そこで拾った品を売って暮らす。あの日拾った石の売却から迷宮の存在が世間に知られ、のどかな村は人の集まる町へ変わる。身近な人の喪失を通じてその変化を実感した主人公は、村を元に戻そうと、商いで冒険者の攻略を支え始める。しかし迷宮をなくしても人も町も元には戻らず、稼ぎを失った町には荒廃が残る。

主人公は商人であり、攻略の主役となる冒険者を支える存在である。自ら浅層に潜って品や情報を得ることと、売買・装備・資金・関係によって他者の探索を可能にすることを、一つのゲームループに結ぶ。

迷宮をなくす目的は幼少期から持っているのではない。主人公も村人も当初はダンジョンを知らず、生計のための商い、村の変化を実感する出来事、コアを壊せば迷宮をなくせるという知識を経て、攻略の動機が形になる。そこまでを短い導入とし、その後に通常の商人ゲームループが始まる想定とする。

中心となる問いは、**自分の目的のために、他人をどこまで危険にさらせるか。** それと並んで、**物はいつ「商品」になるのか。売った後の出来事に商人はどこまで関わっているのか。** を繰り返し扱う。

利益、攻略、人の安全、町の繁栄、迷宮を消したいという願いは、ときに衝突する。善悪メーターや正解のラベルで結論を示さず、人・物・町に起きた結果を見せる。

## 3. 世界と幼少期の基準

### 迷宮

- 迷宮は世界のどこかでときおり発生する、超自然的な現象である。洞窟、遺跡、地下施設などが突然変わる。
- 起源は説明しない。科学・魔法・宗教・古代文明による真相解明を本筋に置かない。
- 主人公は迷宮を発生させていない。召喚、起動、魔法の失敗、選ばれた者という設定にはしない。
- 最奥にあるダンジョンコアを壊すことで、迷宮をなくすことができる。主人公は導入の終盤でその方法を知る。消失・恒久的不活性化の具体的な見せ方と、景観・移動の切り替えは未確定。
- 今作の迷宮だけが世界で唯一の迷宮ではない。別の町や時代の物語も成立する。
- 主人公と村人は、当初ダンジョンというものを知らない。洞窟の危険と友の死は知るが、外来者が鉱物から正体を見抜くまで、ダンジョンとしては認識していない。

### 友との時間

主人公はのどかな村で育ち、近くの普通の洞窟を幼なじみと遊び場にしている。石を拾い、隠れ、冒険者ごっこをする。友は主人公より少し裕福な家庭の子で、二人は本当の友達である。

友が持つ剣は、ありふれた鉄の剣である。その存在と後の任意取得は基準として確定する。木剣ではなく本物の鉄でできた剣を無邪気に自慢し、主人公が少し羨む描写は、関係を表す演出候補として引き継ぐ。

### 発生、脱出、死の確認

その日、洞窟へ入ろうと提案するのは主人公である。中で見たことのない石を拾い、その直後に洞窟が迷宮化する。見慣れた道が消え、空間が変わり、未知の生き物が現れる。主人公は逃げ延び、友は命を落とす。

洞窟へ誘ったこと、石を拾ったこと、その直後に異変が起きたことが、主人公の中では結びつく。ただし、石の取得と迷宮化に実際の因果関係はない。石を起動アイテムにしたり、主人公を迷宮発生の原因にしたりしない。

落ち着いた後、主人公は再び洞窟へ入り、幼なじみの遺体を発見する。その脇に鉄の剣が落ちている。**幼なじみの死は確定している。** 最深部で生存が判明する救出劇や、結末で喪失を取り消す展開にはしない。主人公の罪悪感と、発生原因に責任がないという事実は両立する。

剣を拾うかどうかの選択の後、主人公は家族を呼び、遺体が回収・収容され、洞窟は立ち入り禁止になる。この経過はテキストで簡潔に伝える予定。家族と村人は死と洞窟の危険を知るが、「迷宮が発見された」とは認識しない。主人公がダンジョンと知りながら存在を隠す筋立てでもない。

## 4. 最初の所有の選択

遺体の脇に落ちている鉄の剣を拾うか、残すかをプレイヤーが選ぶ。拾った場合、その個体は「幼なじみの鉄の剣」という名称で手に入る。名称は思い出を示すために必要なもので、特別な性能や希少性を意味しない。幼なじみの固有名を含めた最終表示名は未確定。

拾わなければ、その剣は二度と登場しない。再訪・他者からの届け物・通常生成などで取り直せるようにはしない。取得しなくても導入と本編は進み、友の記憶と自責は残る。旧案の小袋・小銭などを含む遺体全体の取得選択は、今回の導入に自動で追加しない。

ゲームは行動を「盗み」「悪い選択」と採点しない。家族の後の言葉に、手元の品や自分の行動が重なる描写は演出候補であり、台詞や後続イベントは未確定。

### 普通の鉄の剣

剣に呪い、伝説、隠された魔力を足さない。原文の **18G** は、低い市場価値と大きな個人的価値の差を示す例である。現在の商品価格への一括適用は行わない。

取得後の保管、売却、家族への返却、展示、誰かへ渡す、紛失などは従来の構想として残す。剣は記憶の証・自責の象徴であり、攻略や結末に必要な鍵にはしない。主人公による使用も原文の候補だが、Web版の「武器・防具を装備せず、護衛に頼る」現仕様との調整が必要になる。

物語上の重要性とレアリティは別である。普通の品でも、その個体の来歴を残す価値がある。後年、高価な冒険者の遺品を拾ったときにも、幼少期と同じ問いが返ってくる。遺族、仲間、ギルド、発見者の主張や町の慣習が一致するとは限らない。「回収者のものになる」という法・慣習も候補であり、世界全体の法律としては未確定。

## 5. 商いが始まり、町が変わる

村にとって、そこは「子供が死んだ危険な洞窟」である。ダンジョンという存在自体を知らず、危険だから立ち入りを禁じた。まだ冒険者が集まる場所ではない。

立ち入り禁止後も主人公は洞窟に入り、そこで品物が取れることに気づく。拾った品を売ることが生活になり、時間が飛んだ後、成長した主人公は小さな商いを営んでいる。この時点ではダンジョン攻略が目的ではない。

転機は、店を訪れた人物が、幼い日に迷宮化の直前に拾った石を見つけて買うこと。その石はダンジョンでしか見つからない鉱物で、購入者が出所をダンジョンだと見抜く。噂が広まり、冒険者が村を訪れ始める。主人公と村人も、その場所の正体を知るようになる。購入者の職業・名前・価格は未確定。旧案の「青い鉱石が複数の市場を経由する」という例より、この同じ石の売却を優先する。

村が町へ変わる中で、主人公は身近な人の離郷や被害を通じて、かつての暮らしが失われることを実感する。幼なじみの家族の離郷、昔からの知人の離郷、家族が暴漢に襲われる事件などが候補であり、採用する場面は未確定。その後、最奥のコアを壊せばダンジョンをなくせると知り、「自分のせいで変わった村を元に戻したい」という思いを攻略の目的へ結びつける。

### 物語の流れ

| 段階 | プレイヤーが経験すること | 次につながる意味 |
|---|---|---|
| 幼少期 | 主人公の誘い、石の取得、迷宮化、脱出、遺体発見、剣の任意取得 | 実際の因果と一致しない自責、記憶を背負う普通の品 |
| 禁止後〜時間経過 | 遺体の収容、立ち入り禁止、その後も洞窟で採集・売買 | 生計のために商人になる |
| 発見 | 店であの日の石を売り、購入者がダンジョンと気づく | 噂と冒険者の来訪が村を変え始める |
| 導入の転機 | 身近な人の離郷・被害等を実感し、コアの破壊方法を知る | 村を元に戻すために攻略を支える決意 |
| 本編 | 売買、装備提供、冒険者支援、利益と事故、成功と死 | 目的のために他者を危険へ送る葛藤 |
| 攻略とその後 | 迷宮はなくなるが、人々が残り、稼ぎが失われる | 治安の悪いさびれた町が残り、昔の村は戻らない |

章数、年齢、年数、台詞、最深階、結末の分岐数は未確定。最後の段階は長期的な方向であり、現時点で遊べるエンディング仕様ではない。

## 6. 町の発展が生む矛盾

最初の商いが人を呼び、村が変わった後に、主人公は迷宮を消す目的を持つ。迷宮を消すために強い冒険者を支えれば、市場・宿・鍛冶・医療・物流をさらに必要とし、人と金が集まる。昔の村を取り戻すための努力も、その変化を進めてしまう。

発展そのものを悪としない。医療、道路、学校、仕事、商品、防衛が良くなる一方、家賃、犯罪、賭博、格差、立ち退き、文化の変化も起こりうる。どの施設や事件を実装するかは後で選ぶ。

現在想定する結末では、迷宮攻略により町の主な収入源が失われる。来訪者が全員去るわけではなく、移住する資金や行き先のない人々も残る。迷宮がなくなっても治安は回復せず、さびれた町が残る。昔の住民や幼なじみの家族が自動的に戻ることもない。

主人公が向き合うのは、友も子供時代も取り戻せず、**迷宮をなくすことと、故郷を元に戻すことは同じではなかった**という結果である。終盤の演出と分岐の有無は未確定。旧案の多角化・復興・未来を選ぶ構想を、必ず成立する救済的な結末として扱わない。発展段階や経済式も未確定である。

## 7. 品が人と世界へ及ぼす結果

Item Consequence System の基本は **品 × 持ち主 × 状況 = 結果**。売却後も重要な品の個体を追跡し、使用、転売、所有者の変化、事故、成功を来歴として結ぶ。

結果には幅を持たせる。食料で誰かの生活が助かる、売った防具で生き延びる、支えた新人が成長する、道具から産業が生まれる、強力な武器が攻略と町の暴力の両方を増やす、危険な遺物が大事件に関わる、といった大小・正負の帰結を含む。すべての取引を大事件にしない。

普通の品は性質や用途による小さな影響を中心にし、少数の World Impact Items には個別のイベント連鎖を設ける構想とする。幼なじみの剣の重要性は、その種の特殊効果を持つことを意味しない。

危険性は最初から確率つきで明示せず、観察、証言、調査、研究などで知る。知るには時間・費用・人間関係が要る。原文の段階式鑑定は候補であり、旧台帳の「鑑定を作らず来歴と証言で知る」方針との調整は未了である。

販売、拒否、保管、貸与、寄贈、返却、調査、廃棄、解体、当局への引き渡し、闇市場、競売などは行動候補。全ての実装は決めていない。どの選択も自動的な道徳上の正解にせず、「売っただけだ」という言葉に複数の人が異なる反応を返す。

## 8. 時間と情報の基準

### 一つの世界時計

町、店、移動中、迷宮内で同じ時間が進む。迷宮で過ごした一日は町でも一日であり、不在中も冒険者、商売、建築、人間関係、品の影響が進行する。

大きな更新はゲーム内の日ごとに Daily World Tick で行う方向とする。町では夜から朝、迷宮では休息・焚き火など、場所に合った日付変更を見せる。日中を行動時間、時間帯、時間数のどれで扱うかは未確定。「連続した時間」は、放置中・メニュー中・アプリ終了中にも現実時間で進むという決定ではない。

### World Truth と Player Knowledge

| 概念 | 意味 |
|---|---|
| World Truth | 世界で実際に起きたこと。到達階、負傷、死亡、品の移動など |
| Player Knowledge | 主人公が、目撃・報告・会話・証拠などから現在までに知った内容 |
| Event Time | 出来事が起きた時刻 |
| Discovery Time | 主人公がその情報を得た時刻 |

出来事が発生しただけでは通知しない。到達記録は帰還者の報告で初めて公表されうる。全滅した一行は、内部で死が確定しても、町では出発中のまま、帰還予定を過ぎれば遅延となる。別の一行が遺体や日記を発見して初めて消息が伝わる。

冒険者表示は、知っている出発日、予定期間、目的地、出発時の構成員、帰還予定、最終確認情報を使う。現在地やHPを遠隔で追跡する表示にはしない。本人に会う、現場に居合わせるなどの確認機会は認める。

情報の経路は、帰還報告、ギルド、酒場の噂、旅商人、新聞・掲示板、個人的な会話、遺体・手紙・装備など。噂には遅延や誤りがありうるが、誤りの割合や訂正方法は未確定。町で広く知られた事件は帰還時に知りやすく、私的な事情や凶器と自分の売った品の関係は別途調べて知る。

**主人公が情報を得るまで世界の結果を待たせない。** 他方、情報を遅らせるために自分が目撃した出来事まで伏せる必要はない。

## 9. 関係を遊びで作る

人物の重要さを長い説明だけに頼らず、顔なじみとの売買、貸し借り、助け合い、探索、繰り返し会う日常から作る。かつて支えた冒険者が英雄になることも、恨むことも、いなくなることもありうる。

ペットは継続検討する構想である。店に寄りついた犬や猫と、名前・食事・日常の触れ合いを重ね、やがて探索へ同行する。主人公が倒れた際、操作をペットへ移して走る・隠れる・助けを探す遊びを繰り返せれば、機能への信頼から愛着が生まれる。

ペットの死を全周回の固定イベントにしない。救助、負傷、喪失、両者の生死は状況と判断から生じる構想とする。種別、操作、救助経路、主人公の死亡ルールとの接続は未確定で、直近の実装対象ではない。

Undertale から受け取るのは、普段のゲーム行動の意味を問い直す発想である。平和主義ルート、善悪ルート、第四の壁などの表面的な模倣を目指さない。Merchan では売買そのものが物語になる。

## 10. 未確定事項と次の設計

| 項目 | 今後決めること |
|---|---|
| 主人公・幼なじみ | 年齢、名前、性格、家族、関係、幼少期から本編までの年数 |
| 遺体と剣 | 任意取得の具体操作、最終表示名、価格、取得後の返却・展示等。剣の存在と未取得なら再登場しないことは確定 |
| 石と迷宮化 | 迷宮化直前に固有鉱物がある理由の整合、後年まで保管していた事情、客が見つける状況。石の取得と迷宮化に因果はない |
| 開業と村の変化 | 店を手に入れる過程、初期資産、石の購入者、立ち入り禁止の扱い、動機を作る離郷・被害等の場面、コアの情報源 |
| 商人の直接行動 | 原文の剣の使用候補と、Web版の戦わない商人の整合 |
| 日中の時間 | 時間帯と行動コスト、営業・移動・複数日滞在の機会損失 |
| 遠征 | 結成、目的地、日数、物資、撤退、負傷、未帰還、救助、支援契約 |
| 情報 | 伝達者、配信条件、報告範囲、噂の精度、訂正、調査・鑑定の位置づけ |
| 所有と来歴 | 慣習、権利を主張する人、貸与の権利、追跡対象、保存の粒度 |
| 町と品の影響 | 発展と衰退の方式、来訪・離郷条件、通常効果と個別連鎖の比率。多角化の旧構想は想定する結末と要調整 |
| 終盤・ペット | コア破壊の具体条件、活動終了の形、荒廃した町を見せる演出、分岐の有無、救助と死亡ルール |

**次の設計テーマは冒険者の遠征システム。** 商人の販売・装備提供・出資が、出発判断、到達目標、物資、撤退、帰還後の報告にどう作用するかを、まず小さな一往復で具体化する。日・週・月のゲームループはその遠征と営業の関係から詰める。設計は [EXPEDITION_SYSTEM.md](EXPEDITION_SYSTEM.md) にまとめた。

今後の追加改善は、商人らしさ、商いと攻略の接続、知りうる形で届く結果、選択の葛藤、不在中も動く世界、小規模開発で実現できる範囲、の6点で評価する。
