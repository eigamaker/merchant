## 2. 作品の核

> 幼い日に突然現れた迷宮で友を失った主人公は、故郷の静かな暮らしを取り戻そうとする。自分では迷宮を攻略できないため、商売を通じて冒険者を支え、攻略を可能にする町を育てていく。しかし、その商いこそが故郷を変え、他人を危険へ送り出し、失われた過去には戻れないことを明らかにしていく。

主人公は商人であり、攻略の主役となる冒険者を支える存在である。自ら浅層に潜って品や情報を得ることと、売買・装備・資金・関係によって他者の探索を可能にすることを、一つのゲームループに結ぶ。

中心となる問いは、**自分の目的のために、他人をどこまで危険にさらせるか。** それと並んで、**物はいつ「商品」になるのか。売った後の出来事に商人はどこまで関わっているのか。** を繰り返し扱う。

利益、攻略、人の安全、町の繁栄、迷宮を消したいという願いは、ときに衝突する。善悪メーターや正解のラベルで結論を示さず、人・物・町に起きた結果を見せる。

## 3. 世界と幼少期の基準

### 迷宮

- 迷宮は世界のどこかでときおり発生する、超自然的な現象である。洞窟、遺跡、地下施設などが突然変わる。
- 起源は説明しない。科学・魔法・宗教・古代文明による真相解明を本筋に置かない。
- 主人公は迷宮を発生させていない。召喚、起動、魔法の失敗、選ばれた者という設定にはしない。
- 最深部が攻略されるまで活動を続け、攻略後は消失または恒久的な不活性化に至る。具体的な景観・移動・経済への切り替え方は未確定。
- 今作の迷宮だけが世界で唯一の迷宮ではない。別の町や時代の物語も成立する。

### 友との時間

主人公は小さな田舎町で育ち、近くの普通の洞窟を幼なじみと遊び場にしている。石を拾い、隠れ、冒険者ごっこをする。友は主人公より少し裕福な家庭の子で、二人は本当の友達である。

友が持つ小さな鉄の剣は、その関係を表す候補である。木剣ではなく本物の鉄でできた剣を無邪気に自慢し、主人公は少し羨む。市場ではありふれた品でも、子供にとっては宝物であることを先に体験させる。

### 発生、脱出、死の確認

洞窟にいる間に迷宮が突然発生する。見慣れた道が消え、空間が変わり、未知の生き物が現れる。主人公は逃げ延び、友は命を落とす。

その後、主人公が戻る、または捜索に加わる流れで遺体を発見する。**幼なじみの死は確定している。** 最深部で生存が判明する救出劇や、結末で喪失を取り消す展開にはしない。主人公の罪悪感と、発生原因に責任がないという事実は両立する。

家族と町は迷宮と死を知り、遺体の回収・埋葬を行う。主人公が迷宮の存在を隠す筋立てにはしない。発見・回収への同行者、演出、会話の順序は詳細設計で決める。

## 4. 最初の所有の選択

遺体の発見時にプレイヤーへ操作を戻し、持ち物を調べられる構成を優先する。剣、小袋、小銭、飾り、食べ物などが候補になる。

「何も取らない」「剣だけ取る」「一部を取る」「すべて取る」を選べる方向で設計する。取得は強制せず、取らなくても物語を進められるようにする。ただし、正確な所持品と操作仕様は未確定である。

ゲームは行動を「盗み」「悪い選択」と採点しない。家族が品の欠落にすぐ気づくとは限らず、後の「あの子は、あの小さな剣が好きだった」という言葉に、手元の品や自分の行動が重なる。

### 普通の鉄の剣

剣に呪い、伝説、隠された魔力を足さない。原文の **18G** は、低い市場価値と大きな個人的価値の差を示す例である。現在の商品価格への一括適用は行わない。

保管、売却、家族への返却、展示、誰かへ渡す、紛失など、その後の扱いが構想に含まれる。主人公による使用も原文の候補だが、Web版の「武器・防具を装備せず、護衛に頼る」現仕様との調整が必要になる。

物語上の重要性とレアリティは別である。普通の品でも、その個体の来歴を残す価値がある。後年、高価な冒険者の遺品を拾ったときにも、幼少期と同じ問いが返ってくる。遺族、仲間、ギルド、発見者の主張や町の慣習が一致するとは限らない。「回収者のものになる」という法・慣習も候補であり、世界全体の法律としては未確定。

## 5. 商いが始まり、町が変わる

町は迷宮の存在を知っているが、当初の評判は「子供が死んだ危険な洞窟」に近い。遠い、危ない、価値が分からない場所には、強い冒険者が自然に集まる理由がない。

成長した主人公は迷宮を放っておけず、浅い場所へ戻る。動機は最初から金儲けでなくてよい。石、薬草、牙、鉱物、古い貨幣などを持ち帰り、地元の人や職人に少額で売るうちに、迷宮の品が売れることを知っていく。既成の大店主から始めることは前提にしない。

転機は一件の普通の売買である。例えば、主人公が35Gほどで売った「青い鉱石」が、商人・職人・大きな市場を経由し、町の外で用途と価値を認められる。噂が伝わり、冒険者が来る。品名・価格・流通経路は例であり、経済を意図的に立ち上げたのでなく、売った品が町を変え始める構造を基準にする。

### 物語の流れ

| 段階 | プレイヤーが経験すること | 次につながる意味 |
|---|---|---|
| 幼少期 | 洞窟遊び、発生、脱出、遺体発見、遺品の選択、葬送 | 喪失と、品の市場価値では測れない価値 |
| 数年後 | 浅層の採集、小さな売買 | 商人になる過程 |
| 発見 | 売った素材の価値が外で認められ、噂が戻る | 一件の取引が自分の外へ広がる |
| 成長 | 売買、装備提供、冒険者支援、町の発展 | 他者を通じた攻略 |
| 葛藤 | 利益と事故、成功と死、豊かさと立ち退き | 攻略を望む行動の代償 |
| 攻略とその後 | 迷宮の活動終了、産業と人間関係の変化 | 過去は戻らず、今後を選ぶ |

章数、年齢、年数、台詞、最深階、結末の分岐数は未確定。最後の段階は長期的な方向であり、現時点で遊べるエンディング仕様ではない。

## 6. 町の発展が生む矛盾

迷宮を消すために、強い冒険者が必要になる。冒険者を支えるために市場・宿・鍛冶・医療・物流が育ち、人と金が集まる。昔の町を取り戻すための努力が、昔の町へ戻れなくする。

発展そのものを悪としない。医療、道路、学校、仕事、商品、防衛が良くなる一方、家賃、犯罪、賭博、格差、立ち退き、文化の変化も起こりうる。どの施設や事件を実装するかは後で選ぶ。

迷宮攻略は、町の主な収入源を失うことにもなる。農業、加工、工芸、教育、交易、物流、研究などへの多角化は、攻略後の町を考えるための構想である。迷宮依存の程度によって町の将来が変わる方向を目指すが、発展段階や経済式、産業の数は未確定。

主人公が向き合うのは、友も子供時代も取り戻せないという事実と、**今ここにいる人たちのために、どのような未来を残すか**という問いである。

## 7. 品が人と世界へ及ぼす結果

Item Consequence System の基本は **品 × 持ち主 × 状況 = 結果**。売却後も重要な品の個体を追跡し、使用、転売、所有者の変化、事故、成功を来歴として結ぶ。

結果には幅を持たせる。食料で誰かの生活が助かる、売った防具で生き延びる、支えた新人が成長する、道具から産業が生まれる、強力な武器が攻略と町の暴力の両方を増やす、危険な遺物が大事件に関わる、といった大小・正負の帰結を含む。すべての取引を大事件にしない。

普通の品は性質や用途による小さな影響を中心にし、少数の World Impact Items には個別のイベント連鎖を設ける構想とする。幼なじみの剣の重要性は、その種の特殊効果を持つことを意味しない。

危険性は最初から確率つきで明示せず、観察、証言、調査、研究などで知る。知るには時間・費用・人間関係が要る。原文の段階式鑑定は候補であり、旧台帳の「鑑定を作らず来歴と証言で知る」方針との調整は未了である。

販売、拒否、保管、貸与、寄贈、返却、調査、廃棄、解体、当局への引き渡し、闇市場、競売などは行動候補。全ての実装は決めていない。どの選択も自動的な道徳上の正解にせず、「売っただけだ」という言葉に複数の人が異なる反応を返す。

## 8. 時間と情報の基準

### 一つの世界時計

町、店、移動中、迷宮内で同じ時間が進む。迷宮で過ごした一日は町でも一日であり、不在中も冒険者、商売、建築、人間関係、品の影響が進行する。

大きな更新はゲーム内の日ごとに Daily World Tick で行う方向とする。町では夜から朝、迷宮では休息・焚き火など、場所に合った日付変更を見せる。日中を行動時間、時間帯、時間数のどれで扱うかは未確定。「連続した時間」は、放置中・メニュー中・アプリ終了中にも現実時間で進むという決定ではない。

### World Truth と Player Knowledge

| 概念 | 意味 |
|---|---|
| World Truth | 世界で実際に起きたこと。到達階、負傷、死亡、品の移動など |
| Player Knowledge | 主人公が、目撃・報告・会話・証拠などから現在までに知った内容 |
| Event Time | 出来事が起きた時刻 |
| Discovery Time | 主人公がその情報を得た時刻 |

出来事が発生しただけでは通知しない。到達記録は帰還者の報告で初めて公表されうる。全滅した一行は、内部で死が確定しても、町では出発中のまま、帰還予定を過ぎれば遅延となる。別の一行が遺体や日記を発見して初めて消息が伝わる。

冒険者表示は、知っている出発日、予定期間、目的地、出発時の構成員、帰還予定、最終確認情報を使う。現在地やHPを遠隔で追跡する表示にはしない。本人に会う、現場に居合わせるなどの確認機会は認める。

情報の経路は、帰還報告、ギルド、酒場の噂、旅商人、新聞・掲示板、個人的な会話、遺体・手紙・装備など。噂には遅延や誤りがありうるが、誤りの割合や訂正方法は未確定。町で広く知られた事件は帰還時に知りやすく、私的な事情や凶器と自分の売った品の関係は別途調べて知る。

**主人公が情報を得るまで世界の結果を待たせない。** 他方、情報を遅らせるために自分が目撃した出来事まで伏せる必要はない。

## 9. 関係を遊びで作る

人物の重要さを長い説明だけに頼らず、顔なじみとの売買、貸し借り、助け合い、探索、繰り返し会う日常から作る。かつて支えた冒険者が英雄になることも、恨むことも、いなくなることもありうる。

ペットは継続検討する構想である。店に寄りついた犬や猫と、名前・食事・日常の触れ合いを重ね、やがて探索へ同行する。主人公が倒れた際、操作をペットへ移して走る・隠れる・助けを探す遊びを繰り返せれば、機能への信頼から愛着が生まれる。

ペットの死を全周回の固定イベントにしない。救助、負傷、喪失、両者の生死は状況と判断から生じる構想とする。種別、操作、救助経路、主人公の死亡ルールとの接続は未確定で、直近の実装対象ではない。

Undertale から受け取るのは、普段のゲーム行動の意味を問い直す発想である。平和主義ルート、善悪ルート、第四の壁などの表面的な模倣を目指さない。Merchan では売買そのものが物語になる。

## 10. 未確定事項と次の設計

| 項目 | 今後決めること |
|---|---|
| 主人公・幼なじみ | 年齢、名前、性格、家族、関係、幼少期から本編までの年数 |
| 遺体と剣 | 正確な所持品、取得・返却・展示の操作、価格、剣が常にあるか |
| 開業 | 初期の資産、店舗の有無、店を手に入れる過程、初期NPC構成 |
| 商人の直接行動 | 原文の剣の使用候補と、Web版の戦わない商人の整合 |
| 日中の時間 | 時間帯と行動コスト、営業・移動・複数日滞在の機会損失 |
| 遠征 | 結成、目的地、日数、物資、撤退、負傷、未帰還、救助、支援契約 |
| 情報 | 伝達者、配信条件、報告範囲、噂の精度、訂正、調査・鑑定の位置づけ |
| 所有と来歴 | 慣習、権利を主張する人、貸与の権利、追跡対象、保存の粒度 |
| 町と品の影響 | 発展の方式、移住条件、通常効果と個別連鎖の比率、多角化 |
| 終盤・ペット | 攻略の条件、活動終了の形、結末、救助と死亡ルール |

**次の設計テーマは冒険者の遠征システム。** 商人の販売・装備提供・出資が、出発判断、到達目標、物資、撤退、帰還後の報告にどう作用するかを、まず小さな一往復で具体化する。日・週・月のゲームループはその遠征と営業の関係から詰める。

今後の追加改善は、商人らしさ、商いと攻略の接続、知りうる形で届く結果、選択の葛藤、不在中も動く世界、小規模開発で実現できる範囲、の6点で評価する。
