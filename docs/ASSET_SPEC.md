# アセット契約

更新日: 2026-08-18

## 正とする情報

実行時パスとキャラクター契約は `src/game/assets.ts`、タイル登録とレイヤーの初期値は `src/game/mapTiles.ts` を正とします。タイルの隣接関係から表示を計算する自動接続は使いません。

## マップタイル

配置先は `public/assets/map-tiles/` です。画像はPNG、RGBA、nearest-neighborで扱います。

| ファイル | 寸法 | 内容 |
| --- | ---: | --- |
| `home-floor.png` | 16×16 | 家の床1枚、通行可能 |
| `home-wall.png` | 64×64 | 家の壁。16×16を4列×4行の手動選択フレーム |
| `dungeon-floor.png` | 16×16 | ダンジョンの床1枚、通行可能 |
| `dungeon-wall.png` | 64×64 | ダンジョンの壁。16×16を4列×4行の手動選択フレーム |

シートの各フレームはエディターで明示的に選択します。隣接セルを追加しても、既に配置したフレームは変わりません。将来、別サイズ・別枚数のシートへ差し替える場合は、登録情報とエディターのフレーム数を更新します。

## キャラクター・UI・オブジェクト

キャラクターは原則128×128px（32pxセル、4方向×4フレーム）です。アイテム、階段、宝箱、罠などのオブジェクトは既存の `public/assets/objects/` 契約を保持します。UIは `public/assets/ui/` に置きます。

当たり判定は画像から推測せず、マップの明示 `collision` レイヤー（`true`=通行可）を使います。旧形式にこの配列がない場合だけ、読み込み時に論理タイルの初期値から補完します。新しいマップJSONは `layers`、`tileFrames`、`collision`、マーカーを保存します。

## 検査

`src/game/assetFiles.test.ts` が4つのマップPNGの存在、寸法、RGBA形式と、保持対象のactor/UI/item/object素材を検査します。
