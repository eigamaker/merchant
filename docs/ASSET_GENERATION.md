# 生成AI向けアセット制作指示

更新日: 2026-08-18

ゲームへ納品するマップ素材は、home/dungeonそれぞれの床1枚と壁の16フレームシートを個別に生成します。最終寸法は [`ASSET_SPEC.md`](ASSET_SPEC.md) を優先します。

## マップ素材

床は16×16pxの読みやすい単一タイル、壁は64×64pxの4×4シートです。壁の各フレームは手動配置で選択するため、maskや隣接条件の順序は不要です。セル間の余白・罫線・文字は入れません。

## 保持する素材

キャラクターは32×32pxセルの4方向シート、UI、アイテム、階段、宝箱、罠などは既存のファイル名・寸法を維持します。生成画像を置き換える前に `npm test` と `npm run build` を実行します。
