# 統一ピクセルアート

作業ブランチ: `codex/unified-pixel-art`

木の濃茶、クリーム、青緑、えんじ、真鍮色を共通にしたオリジナルの16-bit RPG素材。家も街もダンジョンも、既存のMapDocumentとタイル配置・衝突レイヤーを使用する。部屋全体を背景画像として描画する処理はない。

## 素材と再生成

- AI原本: `assets-src/unified/{humans,monsters,terrain,props}.png`
- 生成方法と実際に使用した全プロンプト: [generation-prompts.json](../assets-src/unified/generation-prompts.json)。内蔵の `image_gen` を使用。出力画像の実寸は1254pxで、指定グリッドに合わせて切り出す。
- 家具原本: `assets-src/home-interior/`。既に分離済みの12家具を継続使用し、共通の木・布・金属の配色に合わせる。
- キャラクター: `public/assets/actors/unified/`（15種）、`assets-src/actors/imported/` → `public/assets/actors/generated/`（主人公と町人5種）。既存IDはセーブ互換のため保持。
- 街・迷宮: `assets-src/map-tiles/sheets/unified/` → `public/assets/map-tiles/generated/`。
- 家具: `assets-src/map-tiles/sheets/merchant/`。棚・ベッド・宝箱・テーブル・カーペット・カウンター・樽・箱・ドア・椅子・机・ランタンを独立した透過素材として配置。
- 全30商品アイコンと従来のフォールバック用画像も同じ原本から置換。

`npm run assets:art` で原本からスプライトとタイルを再生成し、実行用カタログを更新する。マップ配置は変更しない。家具のみの再生成は `node scripts/build-home-interior.mjs`。通常の `npm run assets` / `npm test` / `npm run build` は登録済み素材をビルドする。

`scripts/layout-unified-world.mjs` は初期配置を作るための一度限りの作業用スクリプト。手動編集後に実行すると既定マップを再配置するため、通常のビルドには含めない。

## アニメーション

32×32px、4方向、各4コマ。idle / walk / run / attack / walkAttack / runAttack / hurt / death / interact / cast の10アクション。商人は方向ごとに接地・通過・反対足の接地・通過の4ポーズを新規生成。他の人型は2接地ポーズと脚を寄せる中間ポーズを使用し、頭の輪郭を固定。スライムと植物は足寄せを適用しない。全身が跳ねる歩行と潰れる死亡演出をやめ、足元を揃え、死亡は短い沈み込みとフェードに変更。待機は胴の呼吸、売買は手の動き。走りは歩きより速い再生速度。

## 商品の独立陳列（2026-09-06）

### 描画の高さと接地範囲

`assets-src/shop/furniture-geometry.json` が描画幅・行数・接地行数の共通定義。`src/game/propGeometry.ts` は「描画行数−接地行数」を背後を歩ける行数として計算する。カウンター・棚は3段中下2段、台・宝箱・樽は2段中下1段、ベッドは3段中下2段が接地。上段に別の壁がある場合は壁の通行不可を維持する。壁や建物の画像を高さだけで一律に通行可能にはしない。

カウンター・棚・宝箱・樽は `furniture-proportions.png` から再生成。`build-proportioned-furniture.mjs` は縦横共通倍率で縮小し、余りを透明余白とする。引き延ばしを禁止。カウンターは上部の透明余白に商人の上半身が見える低い天板。商品接点は16px、棚は42px。既定配置は拡大分に合わせて机と客の待機位置を調整済み。保存済みの手動マップで旧2段の棚・カウンターを使っている場合は、新パレットから3段一式を再配置する（周囲の手動配置を自動で上書きしない）。

家では家具の各フレームとその商品・影を共通の接地位置で深度ソートし、人物の足元と比較する。人物が背後へ入ると家具が手前に描かれる。テーブルの商品接点は上段の天板内（上端から11px）で、衝突行の中心とは独立。既存マップの読み込みと通常のパレット配置にも接地範囲を適用する。

- `assets-src/shop/` に全30商品、空のカウンター・棚・テーブル・机、商人歩行の生成原本を保存。内蔵 `image_gen` の全プロンプトは同フォルダーの `generation-prompts.json`。
- 商品アイコンは個別の透過32×32px。薬草、兜、毒消し、各鉱石などを専用画像に修正。一品ごとの対応表は `item-audit.json`、目視用一覧は `docs/item-art-audit.html`。
- 家具の画像 → 接地影 → 商品 → キャラクターの順に合成。陳列商品を家具画像へ描き込まない。通行判定は従来どおり家具のマップ衝突データが担当し、商品や影は追加の障害物にならない。
- `src/game/shopDisplay.ts` に家具ごとの陳列位置と最大サイズを定義。透過余白を除いた商品の中心・下端を表面に合わせる。初期配置は棚4枠、カウンター2枠、テーブル1枠、机1枠。マニュアルマップでは家具を全フレーム配置した場合だけ陳列場所を作る。
- `displayPlacements` に商品UUIDと陳列場所を保存。売れても他の商品は移動しない。家具をクリックして商品を置く・交換する・取り下げる。営業中は変更不可。古いセーブは最初の描画で配置を補完。
- マップ自体の論理グリッドは既存の16pxを維持し、家では2倍表示。32px商品を家具に合わせて整数または半分の倍率で描画する。
- 開発環境の `/?preview=shop` は8点を陳列した操作プレビュー。自動・手動とも保存を行わない。
- 商品の32px枠は維持し、絵の最大辺を26pxから18pxへ約31%縮小。陳列時は最大0.5倍に制限し、小さくした絵を天板いっぱいまで自動拡大しない。接地影も絵の幅から算出し、下端に密着させる。クリック範囲は家具側のまま維持。
- 商品原本は家具・商人を参照して描き直し済み。写実的な粒状質感を減らし、変換時に `SHOP_ITEM_PALETTE` の共通25色へ最近傍で統一（ディザなし）。茶系の輪郭、クリームの光、落ち着いた青・緑・紫を使用。再生成プロンプトは `assets-src/shop/style-revision-prompt.json`。
- 参考観察: [Moonlighterの店内画面](https://interfaceingame.com/screenshots/moonlighter-store/)。商品の間隔、天板の余白、商品下の小さな影を参考にした。内部実装や厳密なピクセル寸法を確認したものではない。

敵の左右歩行は左向き2ポーズから反転し、途中で逆を向かない。人型とモンスターの方向行は明示したメタデータで扱う。迷宮移動でwalk/run、売買でinteract、術師の攻撃でcast、撃破時にdeathを実際に再生する。エディターのキャラクタープレビューにも全アクションが表示される。冒険者の名簿は使用数の少ない外見を優先し、登録した外見が行き渡るようにする。

## 配置と通行

自宅兼店舗を含む街は28×20、16pxタイル。室内のカウンター周辺から2つの出口、街路、右下の迷宮入口まで接続する。家・ダンジョン両方のパレットに統一素材を登録している。

| 素材 | 通行 | 配置・扱い |
| --- | --- | --- |
| 木床、草、街道、洞窟・遺跡・冷えた火山岩 | 可 | ground |
| カーペット | 可 | structure。家具を上に重ねられる |
| 建物壁、屋根、岩壁、水 | 不可 | 建物全体と水面を衝突レイヤーで閉じる |
| 棚、ベッド、机、カウンター、樽、箱、椅子、家具の宝箱 | 不可 | 画像を構成する全タイルを閉じる |
| 樹木、岩、壺、棘 | 不可 | 複数タイルの全占有領域を閉じる |
| 開いたドア | 可 | 開口部の壁を除去。街のドアは入口のくぼみで、別の室内への遷移はない |
| 上り・下り階段 | 可 | 遷移マーカー。上りは上下2タイルの絵 |
| 小さな瓦礫、骨、硬貨 | 可 | 床の装飾。自動生成時も通路を塞がない |
| 壁の松明・レバー・窓 | 不可 | 壁の装飾 |
| 迷宮の宝箱 | 可 | 取得操作は既存のゲームオブジェクト側で処理 |

連続移動は経路を半タイル以下に分割して判定し、遅いフレームでも壁の向こうへ飛び越えない。徘徊する町人も同じ衝突判定を通す。入口・主要マーカーの到達性、全固定障害物、ドア全16セル、全アクターの透明余白・方向・動作差分をテストする。

## 旧素材の整理と互換

旧Craftpixキャラクター、取り込んだ旧タイル、旧商品・主人公原本、重複コピーと旧生成スクリプトを削除。使用中のUIウィンドウ素材とそのライセンス原本は保持している。実行用カタログは再構築し、削除済み素材を配信しない。

過去の手動マップは `retired-map-ids.json` に記録されたIDだけを新しい床・壁・装飾へ移行する。配置・衝突・マーカー座標を維持し、見た目は汎用の代替素材になる。未知のIDのエラーは引き続き表示する。32pxグリッドには32pxの互換素材を使用する。
