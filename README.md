# Dungeon Curio Merchant

ダンジョン探索で一点物の珍品を持ち帰り、町の人々との取引と調査を通じて価値と由来を解き明かす、PCブラウザ向けの2Dターン制RPGです。

## 起動

```powershell
npm install
npm run dev
```

表示された `http://127.0.0.1:5173/` をブラウザで開きます。

## 操作

- 矢印キー / WASD: 移動（ダンジョンで敵にぶつかると弱い攻撃）
- Enter / Space: 町で会話、ダンジョンで拾う・宝箱・階段
- R: ダンジョンから町へ帰還
- Z: 煙玉で近くの敵の追跡を断つ
- I: 持ち物
- L: 商人の記録
- Q: 冒険者ギルドの依頼一覧
- F1 / F2 / F3: 町で手動保存
- H: 操作一覧

## 現在実装されているMVP

- 歩ける町、顧客5人、クエスト15本のデータ定義
- 8階層のシード固定ダンジョン、ターン制の敵、宝箱、罠、遺体、容量制の持ち物
- 鑑定、展示、買い手ごとの価格差、1回の反提案、関係値
- 黒い長剣の発見、売却、売却後イベント、墓所調査、真名判明のストーリー
- 商品履歴、IndexedDBの自動保存1枠・手動保存3枠

本番アートは `src/game/assets.ts` の論理アセットIDを保ったまま、仮テクスチャをスプライトシート読込へ置き換える想定です。

タイル、壁、建物、マップレイヤーの制作規約は [`docs/ASSET_SPEC.md`](docs/ASSET_SPEC.md) を参照してください。
